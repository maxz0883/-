# Vitalis Predict — памятка по защите данных

Откройте `index.html` локально или разместите папку на статическом хостинге.

## Состав

- `index.html` — сайт-памятка с архитектурой, чек-листом и API-контрактом.
- `styles.css` — адаптивная стилизация.
- `script.js` — интерактивный чек-лист и кнопка копирования API-контракта.

## Архитектурное правило

Frontend не должен содержать приватные ключи. Данные передаются на backend по HTTPS в зашифрованном конверте. Backend повторно валидирует схему, расшифровывает запрос в памяти и применяет контроль доступа, TTL и аудит.

## Перед продакшеном

1. Подключить реальный KMS/Vault.
2. Добавить серверную проверку согласия, ролей, размера и срока хранения.
3. Настроить ротацию ключей, резервные копии и журналирование без PII.
4. Проверить удаление данных и реагирование на инциденты.
